# Follow up on inspection recommendations

**Assigned:** Dana Whitfield

We order property inspections, read the findings, note the recommendations,
and then nothing. At renewal nobody checks whether the handrail was ever
installed, so the same recommendation gets written again.

- Recommendations as tracked items with a due date and an owner
  (underwriting/inspections/track-inspection-recommendations.feature.md).
- Renewal surfaces open recommendations to the underwriter rather than burying
  them in the inspection PDF
  (underwriting/inspections/review-inspection-findings.feature.md).
- Overdue safety-critical items drive a referral, not a quiet renewal.
