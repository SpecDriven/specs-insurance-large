# Define the scope of a data subject request

**Assigned:** Dana Whitfield

When a privacy request arrives, we search the systems someone remembers. There
is no list of where personal information lives, so each response is a
different shape and none is demonstrably complete.

- A maintained inventory of systems holding personal information
  (compliance/privacy/protect-nonpublic-personal-information.feature.md).
- Requests run against the inventory, with per-system completion recorded
  (compliance/privacy/handle-data-subject-request.feature.md).
- Access to the assembled response is itself logged
  (platform/access/log-sensitive-data-access.feature.md).
